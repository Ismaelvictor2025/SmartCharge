# SmartCharge — Support

Welcome to the SmartCharge support page.

SmartCharge is an educational iOS application developed for UTS 40005 Advanced iOS Applications.

## About the Application

SmartCharge helps electric-vehicle drivers plan journeys, estimate battery range, assess charging stations and review route safety.

## Support Topics

- Journey planning and navigation
- Battery range calculations
- Charging station recommendations
- Notifications and widgets
- Application errors and accessibility
